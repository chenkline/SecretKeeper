## 12. 渲染约定（换行与悬挂标点）

设计源是 Figma REST API 的原始 JSON。`characters` 字段是**不带换行**的原始串，
换行只发生在 Figma 的渲染期，`absoluteBoundingBox` 记录的却是换行后的宽高。
直接单行输出会让本地字体度量略宽的文字溢出外盒、被容器的 `clipPath` 裁掉尾巴。

`scripts/render-figma-svg.py` 的处理口径：

1. **按外盒宽度重排**。CJK 与全角标点按 1em、ASCII 按 0.58em、空格按 0.30em 估算，
   超出外盒宽度才折行。整行放得下的一律不折，避免把短文本拆开。
2. **单行文本不折**。若 `absoluteBoundingBox.height` 只够一行，说明该文本在 Figma 里
   本来就是单行（宽度随内容自适应），即便本地度量略宽也保持单行——折了会把
   logo 副标题之类的短文本挤成两行。
3. **行尾标点悬挂**。`，。、；：！？` 等允许压在版心之外，不计入行宽，
   否则行尾句号会被挤到下一行形成孤字。

改渲染器后须复跑门禁：21 张全部通过 XML 合法性、文字数与上述换行检查，
且连续两次渲染的 `sha256` 一致（可复现）。
