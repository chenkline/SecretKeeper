# SecretKeeper UI 设计规范 v3（Bitwarden 桌面风格重设计）

> v3 是**推倒重来**的版本：不继承 v1/v2 的任何布局信息（v1 画板、v2 screenshots
> 均作废归档）。视觉真相源为本规范 + `docs/ui/design-v3/bitwarden-desktop.html`
> 三屏设计稿。移动端（Android/iOS）参照 **Bitwarden 移动应用**风格，见 §7。

---

## 1. 布局骨架（v3 核心，替代 v1/v2 的 208px 宽文字侧栏）

```
+----+----------------------------------------------------------+
| 图 | 工具条：标题  ····  [搜索框通栏]  [导入] [生成主密钥]      | 60px
| 标 +---------------------------+------------------------------+
| 导 | 列表列 380px              | 详情列（弹性）                |
| 航 |  行：40px 圆底图标        |   标题 + 徽章                 |
| 64 |  两行文字                 |   key-value 行（等宽 ID）     |
| px |  hover 行内快捷图标       |   说明文字                    |
|    |  hairline 分隔            |   动作按钮组                  |
| 锁 +---------------------------+------------------------------+
```

- **64px 图标导航栏**（v3 决定性变化）：navy 底 `#1A3B5D`；顶部 36px 圆角
  logo 方块（主蓝底「密」白字）；三个 44x44 图标导航项（机密信息=shield、
  主密钥=key、设置=gear），选中项深底 `#152F4A` + 左缘 3px 主蓝竖条 +
  白图标；底部锁定按钮。**无文字标签**（tooltip 由任务栏/悬停提供）。
- **工具条 60px**：白底 hairline 下缘；左侧页面标题 17px semibold；
  中部**通栏搜索框**（Bitwarden 标志性，max 430px）；右侧动作按钮组。
- **主从布局**：列表列固定 380px 白底；详情列弹性 `#F5F7F9` 底。
  表单页（03/04/05/07/08）为单列窄表单 560px 居左（v2.1 已实施）。

## 3. 组件规范 v3

### 3.1 导航栏（替代 v2 宽侧栏）

| 元素 | 规格 |
|---|---|
| logo 方块 | 36x36 圆角 9，`kBlue` 底白字「密」 |
| 导航项 | 44x44 圆角 10；默认 `kOnNavy` 图标；hover `#1C3B5C`；选中 `kNavyDeep` 底 + 左缘 3px `kBlue` 竖条 + 白图标 |
| 锁定 | 沉底，同导航项规格（lock 图标） |
| 容量卡 | **移除**——容量信息并入 02/06 列表列头（「1 / 2 把」「0 / 15 条」） |

### 3.2 工具条

- 白底、hairline 下缘、高 60、水平内边距 20
- 标题 17 SemiBold 固定左侧
- 搜索框：36 高、圆角 8、`kAppBg` 底、放大镜 15px、placeholder 灰、max 430
- 动作按钮：Primary（`kBlue` 实心白字）与 Secondary（白底 `kLine` 描边），
  高 36、圆角 8、水平 16

### 3.3 列表行（Bitwarden 行语言）

- 高 64；左 40px 圆底分类图标（机密=file-text、主密钥=key-round、
  缺失=file-warning + `kWarnSoft`/`kWarn`）
- 两行文字：主 14 Medium（标题/名称，空则保持留白）、次 12 灰
  （ID 等宽 + 关联名/日期）
- **hover**：整行 `kBlueWash` + 右缘浮现 copy/eye 两个 15px 灰图标
- **选中**：整行 `kBlueWash` + 左缘 3px `kBlue` 竖条
- 行间 1px `kLine` 分隔
- 空态：居中 48px 灰图标 + 「暂无条目」（§v2 3.8 保留）

### 3.4 详情列

- 标题 16 SemiBold + 右侧状态徽章（11px，`kBlueWash`/`kBlue`）
- key-value 行：键 120px 固定 13 灰、值 13（**ID 用等宽**）、
  行间 hairline、行高 8+8
- 说明文字 12 灰；警示块 `kBlueWash` 圆角 8
- 动作按钮组：Primary（复制/导出）+ Secondary（删除，危险红字）

### 3.5 表单页

- 窄卡 560px 居左（内边距 24），输入通栏卡内
- 标签 13 上置；输入 42 高圆角 8；聚焦 2px `kBlue` 描边
- 警示条（密码不可找回）淡黄底圆角 8，在主按钮上方 12
- 主按钮 44 通宽 `kBlue`

### 3.6 解锁页

- 左 44% 品牌区：navy 渐变（`#1A3B5D`→`#123252`），居中盾形 76px 圆角
  20 半透明白、品牌语 28 Bold 白、副语 13 75% 白
- 右 56% 表单区白底：居中 400px 列（选择器/密码/主按钮 44 通宽/错误条/
  页脚声明）

## 5. 移动端（Android / iOS）——参照 Bitwarden 移动应用

共同语言（两平台一致）：

1. **底部 tab 三页**（机密信息/主密钥/设置）——现有结构保留
2. **顶部通栏搜索**置于列表页顶（sticky），Bitwarden 移动同款
3. **列表行**：40px 圆底分类图标 + 两行文字 + 右缘 ›；行卡白底、
   行间 hairline；缺失=黄色圆底警示图标
4. **FAB / 顶部主按钮**：机密列表右下 FAB「+」新增（Bitwarden 移动式）；
   主密钥页顶部按钮组
5. **色彩**：主色 `kBlue` #175DDC、顶栏/表头可着 navy；语义色同桌面
6. 详情页：分区卡（Bitwarden 移动的分组卡）+ 底部动作条

Android 实现：`android/.../ui/` 顶部加搜索框到 SecretsScreen、行卡加
圆底图标、主色改 `#175DDC`、底导航 navy。
iOS 实现：`ios/App` 同步（tab 底色、行结构、色板）。
