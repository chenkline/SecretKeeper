# SecretKeeper UI 设计规范 v2（桌面端重设计）

> 本文档是 v2 界面重设计的**唯一实现依据**。v1 规范（UI设计规范.md）保留作画板
> 存档与页面流程参考；两版冲突时以本文档为准。
> 实现载体：`src/app/theme.h`（token 层）、`src/app/widgets.*`（组件层）、
> `src/app/pages.*`（页面层）。

---

## 0. 背景：v1 的四个问题

对 v1 界面截图的分析（01-09 号画板实现后）：

1. **描边泛滥**：卡片、按钮、输入框、列表全部 1px 灰描边，界面被线条切碎。
2. **层级靠边框不靠背景**：没有"背景分层"概念，所有区域一个底色。
3. **字号/间距无系统**：字号散布，间距随手写，节奏感缺失。
4. **控件观感原始**：按钮全是描边样式、无 hover 反馈、输入框聚焦无响应。

## 1. 设计原则（四条）

1. **内容优先**：机密数据是主角，导航与页头退后—— chrome 用更暗更轻的处理。
2. **分层不用描边**：区域区分靠三层背景明度差，描边只用于输入框与分隔线。
3. **Token 化**：所有颜色/字号/间距/圆角来自 §2 的 token 表，实现层零魔数。
4. **状态可见**：hover/选中/聚焦/禁用四种状态在所有可交互控件上必须存在。

## 2. Token 系统（theme.h v2）

### 2.1 色彩

| Token | 值 | 用途 |
|---|---|---|
| `kAppBg` | `#F2F4F5` | 内容区底（第一层） |
| `kSurface` | `#FFFFFF` | 卡片/面板（第二层） |
| `kSurfaceRaised` | `#F8FAFA` | 卡内嵌套区（搜索框底、表格表头） |
| `kSidebarBg` | `#15262B` | 侧栏（比 v1 的 172C31 更深一档） |
| `kSidebarActive` | `#23444B` | 侧栏选中胶囊 |
| `kAccent` | `#0E6E62` | 主色（按钮实心/选中/链接），比 v1 14786D 深 |
| `kAccentHover` | `#17897B` | 主色 hover |
| `kAccentSoft` | `#E3F1ED` | 选中底/说明块底 |
| `kText` | `#1A262B` | 主文字 |
| `kTextSecondary` | `#5F7078` | 次要文字 |
| `kTextMuted` | `#9AA9AE` | 占位/禁用文字 |
| `kTextOnAccent` | `#FFFFFF` | 主色底上的文字 |
| `kHairline` | `#E9EDEF` | 分隔线/卡片极浅描边（只用于分隔，不做围栏） |
| `kInputBorder` | `#CBD5D9` | 输入框描边（可交互件的描边允许存在） |
| `kInputFocus` | `#0E6E62` | 输入框聚焦描边 |
| `kDanger` | `#B23B3B` | 危险动作/错误 |
| `kDangerSoft` | `#FBEFEE` | 错误条底 |
| `kWarning` | `#A9791C` | 警示文字 |
| `kWarningSoft` | `#FFF6E0` | 警示条底 |
| `kOk` | `#2E7D5B` | 成功/已验证 |

### 2.2 间距（4 基准，全部取自下表）

`4 / 8 / 12 / 16 / 20 / 24 / 32 / 40 / 48`

| 语义 | 值 |
|---|---|
| 控件内边距（按钮/输入） | 12 |
| 卡片内边距 | 20 |
| 卡片间距 | 16 |
| 区块间距 | 32 |
| 页面外边距 | 32 |
| 页头高度 | 96（标题区 64 + 呼吸 32） |

### 2.3 圆角

`4`（徽章/小件）`8`（按钮/输入/行）`12`（卡片）`16`（大容器，v2 暂不用）

### 2.4 字号与字重（FLTK 实现：size + font_for(weight)）

| Token | 值 | 字重 | 用途 |
|---|---|---|---|
| `kFsCaption` | 11 | Regular | 辅助说明、表头 |
| `kFsSmall` | 12 | Regular | 次要说明、页脚 |
| `kFsBody` | 13 | Regular | 正文默认 |
| `kFsRow` | 14 | Medium | 列表行标题 |
| `kFsCardTitle` | 15 | SemiBold | 卡片标题 |
| `kFsPageTitle` | 22 | SemiBold | 页面标题 |
| `kFsDisplay` | 28 | Bold | 解锁页品牌语 |

等宽字体：ID/哈希/路径一律 `FL_COURIER` 13px（`kFontMono`），提升专业感与可复制性。

### 2.5 阴影（FLTK 无模糊，用双层模拟）

卡片 = 纯白底 + 无描边 + **底部 2px `#E3E8EA`**（fill_rounded 时底部多画一条）。
仅"浮起"元素（弹层）可用 1px 描边 + 底 2px 双层。

## 3. 组件规范

### 3.1 按钮（三种，高 36 标准档 / 44 主行动档）

| 型 | 底 | 文字 | hover |
|---|---|---|---|
| Primary | `kAccent` 实心 | 白 | `kAccentHover` |
| Secondary | `kSurface` 实心 + 1px `kInputBorder` | `kText` | 底变 `kSurfaceRaised` |
| Quiet | 无底无边 | `kAccent` | 底变 `kAccentSoft` |
| DangerQuiet | 无底 | `kDanger` | 底变 `kDangerSoft` |

圆角 8；内边距水平 16；主行动（页面唯一主按钮）用 44 高，其余 36。

### 3.2 输入框

高 36，圆角 8，底 `kSurface`，1px `kInputBorder`；**聚焦时描边 `kInputFocus` 且
外加 1 圈 `kAccentSoft`**（focus ring，FLTK 用先画 2px soft 再画 1px border 实现）。
placeholder `kTextMuted`。搜索框内嵌 20px 放大镜，文字左内边距 32。

### 3.3 卡片

白底、12 圆角、无描边（阴影见 §2.5）；卡片标题 15 SemiBold 在内边距 20 顶部；
卡片之间间距 16。

### 3.4 列表行（机密/密钥列表共用）

高 56（v1 的 44 → 56，呼吸感）；结构：左主文字 14 Medium，左下次要 12 灰；
右缘 `›` 箭头灰。hover 整行 `kSurfaceRaised`；选中 = 左缘 **3px `kAccent` 竖条**
+ 整行 `kAccentSoft` 底（不再用描边圆角）；行间不画分隔线（靠行距）。

### 3.5 侧栏

底 `kSidebarBg`；品牌区（密匣 + SecretKeeper 小字）；导航项高 44、圆角 8、
内边距水平 12，hover `#1C333A`，选中 `kSidebarActive` 胶囊 + 白字 + 左缘
3px `kPrimarySoft` 竖条；容量卡与锁定按钮沉底。

### 3.6 滚动条

宽 14；thumb 圆角 7、色 `#C4CFD3`，hover `#AEBDC2`；槽透明。

### 3.7 徽章/胶囊

高 22、圆角 4、内边距水平 8；语义色对（默认=AccentSoft/Accent、缺失=
WarningSoft/Warning、已验证=OkSoft?/Ok）。

### 3.8 空态

列表空 = 居中：48px 灰图标 + 一句说明（13 灰）+ 主行动按钮（Primary 36）。
不允许空白区域无引导。

## 4. 页面规格（九页）

布局骨架（02-09 共用）：

```
+--------+--------------------------------------------------+
| 侧栏   | 页头：标题(22) + 副标题(13)      [动作按钮组]      |  ← 固定，高 96
| 208px  +--------------------------------------------------+
|        | 内容区（滚动）                                    |
| 容量卡 |   卡片 A              卡片 B（详情/表单）           |
| 锁定   |                                                  |
+--------+--------------------------------------------------+
| 页脚：状态文字                              状态胶囊        |  ← 高 32
+--------+--------------------------------------------------+
```

- **01 解锁**：整屏双层（上品牌 55% / 下白卡 45%），品牌区居中盾形+品牌语
  28 Bold；白卡内字段间距 16，主按钮 44 通宽。
- **02 主密钥管理**：左列（列表卡：搜索 + 行列表 List）+ 右列（详情卡 380），
  两列间距 16；页头动作 [导入(Sec)][生成(Pri)]。
- **03/04 生成/导入主密钥**：单列表单卡（max 560 居左），警示条在主按钮上方
  12；主按钮 44 通宽。
- **05 导出**：单列，页脚省略（卡片到底）。
- **06 机密信息**：同 02 双列；列表卡含搜索；空态按 §3.8。
- **07 新增机密**：单列表单卡；字数计数右对齐 12px，超限红。
- **08 导入机密**：单列表单卡。
- **09 安全设置**：三张设置卡纵排（锁定 / 数据与隐私 / 关于），
  每卡标题 15 + 行式条目（label 左 / value 右）。

## 5. 实现映射

| 层 | 文件 | 改动 |
|---|---|---|
| token | `theme.h` | §2 全表新增/改名（v1 名保留别名过渡） |
| 组件 | `widgets.*` | Button 三型+hover、Field focus ring、Card 无描边+底影、List 56 行+hover+左条选中、scrollbar 14 |
| 页面 | `pages.*` | 间距 token 化、页头 96 统一、空态组件、卡片间距 16 |
| 状态 | `pages.*` | List hover 跟踪（FL_MOVE）、输入 focus 重绘 |

## 6. 验收清单

1. 全界面无 1px 灰围栏（输入框与分隔线除外）
2. 所有可交互件有 hover 与禁用态
3. 字号/间距/圆角全部来自 token 表
4. 九页截图逐页对照本文档
5. 滚动/缩放/最大化不回归（v1.5 修复项）
